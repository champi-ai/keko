# Dataset Management Guide

This guide covers how to manage pretraining datasets for Keko's Progressive Neural Networks.

## Overview

The pretraining system generates comprehensive datasets combining multiple data generation strategies. Since dataset generation involves running the base model, it can be time-consuming. The caching system saves generated datasets for reuse.

## Quick Start

### Generate a new dataset
```bash
# Generate and save a dataset without training
python pretraining.py --generate-only --dataset-size 5000

# Generate with custom cache path
python pretraining.py --generate-only --dataset-size 5000 --cache-path datasets/my_dataset.pkl
```

### Use cached dataset for training
```bash
# Default: uses cached dataset if available
python pretraining.py --epochs 3 --batch-size 4

# Force regeneration (ignore cache)
python pretraining.py --no-cache --dataset-size 5000
```

### Inspect cached datasets
```bash
# List all datasets
python manage_datasets.py list

# Inspect specific dataset
python manage_datasets.py inspect datasets/pretraining_dataset.pkl

# Show more samples
python manage_datasets.py inspect datasets/pretraining_dataset.pkl --num-samples 10

# Analyze statistics
python manage_datasets.py analyze datasets/pretraining_dataset.pkl
```

### Delete cached datasets
```bash
# Delete with confirmation
python manage_datasets.py delete datasets/old_dataset.pkl

# Delete without confirmation
python manage_datasets.py delete datasets/old_dataset.pkl --yes
```

## Dataset Structure

Each dataset consists of:
1. **Main file** (`.pkl`): Pickled list of `(input_text, output_text)` tuples
2. **Metadata file** (`_metadata.json`): Human-readable info about the dataset

### Example Dataset Entry
```python
(
    "What is 15 + 27?",  # Input text
    "15 + 27 equals 42"  # Output text (generated by base model)
)
```

## Dataset Composition

The comprehensive dataset includes:

| Category | Percentage | Description |
|----------|-----------|-------------|
| Simple queries | 20% | Math, conversation, basic knowledge |
| Clarification sequences | 15% | Multi-turn dialogues with progressive context |
| Deep conversations | 15% | 30+ turn complex discussions |
| Complex requests | 10% | Multi-step problems |
| Perturbed data | 10% | Character/word-level variations |
| Self-supervised | 15% | Base model generates own Q&A pairs |
| Combinations | 15% | Multiple queries combined |

## File Locations

Default locations:
- Datasets: `datasets/`
- Default cache: `datasets/pretraining_dataset.pkl`
- Metadata: `datasets/pretraining_dataset_metadata.json`

## Command Reference

### pretraining.py Arguments

```bash
python pretraining.py [options]

Training Options:
  --epochs EPOCHS           Number of training epochs (default: 3)
  --batch-size SIZE         Batch size for training (default: 4)
  --dataset-size SIZE       Number of examples to generate (default: 1000)

Dataset Options:
  --no-cache                Regenerate dataset even if cache exists
  --cache-path PATH         Path to cached dataset file
  --generate-only           Only generate and save dataset, skip training
  --inspect-cache           Inspect cached dataset and exit
```

### manage_datasets.py Commands

```bash
python manage_datasets.py <command> [options]

Commands:
  list                      List all cached datasets
  inspect FILEPATH          Inspect dataset contents
  analyze FILEPATH          Analyze dataset statistics
  delete FILEPATH           Delete a cached dataset

Options:
  --dir DIR                 Datasets directory (default: datasets)
  --num-samples N           Number of samples to display (default: 5)
  --yes                     Skip confirmation prompt for delete
```

## Performance Considerations

### Dataset Size Recommendations

| Use Case | Recommended Size | Generation Time* |
|----------|-----------------|------------------|
| Quick testing | 100-500 | ~1-2 min |
| Development | 1,000-5,000 | ~5-15 min |
| Full pretraining | 10,000-50,000 | ~30-120 min |

*Times are approximate and depend on GPU/CPU speed

### Storage Requirements

- **Small dataset** (1,000 samples): ~1-5 MB
- **Medium dataset** (10,000 samples): ~10-50 MB
- **Large dataset** (50,000 samples): ~50-250 MB

### Memory Considerations

During generation:
- Base model: ~1.5 GB VRAM
- Dataset in memory: Scales with size
- Peak usage: ~2-3 GB VRAM for 10k samples

## Best Practices

### 1. Start Small
Generate a small dataset first to verify the generation process:
```bash
python pretraining.py --generate-only --dataset-size 100
python manage_datasets.py inspect datasets/pretraining_dataset.pkl
```

### 2. Use Caching
Always generate once, train many times:
```bash
# Generate once
python pretraining.py --generate-only --dataset-size 10000

# Train multiple times with different hyperparameters
python pretraining.py --epochs 3 --batch-size 4
python pretraining.py --epochs 5 --batch-size 8
python pretraining.py --epochs 10 --batch-size 2
```

### 3. Version Your Datasets
Keep different sizes for different purposes:
```bash
datasets/
├── test_dataset.pkl           # 100 samples for testing
├── dev_dataset.pkl            # 1000 samples for development
├── train_dataset.pkl          # 10000 samples for training
└── full_dataset.pkl           # 50000 samples for full run
```

### 4. Regular Cleanup
Delete old datasets you no longer need:
```bash
python manage_datasets.py list
python manage_datasets.py delete datasets/old_experiment.pkl --yes
```

### 5. Inspect Before Training
Always inspect a dataset before using it for serious training:
```bash
python manage_datasets.py analyze datasets/pretraining_dataset.pkl
```

## Troubleshooting

### Issue: "Dataset not found"
```bash
# Check what datasets exist
python manage_datasets.py list

# If empty, generate one
python pretraining.py --generate-only --dataset-size 1000
```

### Issue: "Out of memory during generation"
```bash
# Generate smaller dataset
python pretraining.py --generate-only --dataset-size 500

# Or generate in batches and combine manually
```

### Issue: "Dataset seems corrupted"
```bash
# Try inspecting it
python manage_datasets.py inspect datasets/pretraining_dataset.pkl

# If it fails, delete and regenerate
python manage_datasets.py delete datasets/pretraining_dataset.pkl --yes
python pretraining.py --generate-only --dataset-size 5000
```

### Issue: "Want to regenerate with different parameters"
```bash
# Use --no-cache to force regeneration
python pretraining.py --no-cache --dataset-size 10000

# Or save to different path
python pretraining.py --generate-only --dataset-size 10000 \
  --cache-path datasets/new_version.pkl
```

## Advanced Usage

### Custom Dataset Generation
You can extend the `ComprehensiveTraining` class to add your own data generation methods:

```python
from pretraining import ComprehensiveTraining

class CustomTraining(ComprehensiveTraining):
    def generate_custom_data(self):
        """Add your custom data generation logic"""
        return [
            ("Custom input 1", "Custom output 1"),
            ("Custom input 2", "Custom output 2"),
        ]

    def create_comprehensive_dataset(self, size=10000, **kwargs):
        dataset = super().create_comprehensive_dataset(size, **kwargs)
        custom_data = self.generate_custom_data()
        dataset.extend(custom_data)
        return dataset
```

### Programmatic Access
```python
from pretraining import ComprehensiveTraining

# Create trainer
trainer = ComprehensiveTraining(base_model, tokenizer, columns, output_proj)

# Generate dataset
dataset = trainer.create_comprehensive_dataset(
    size=5000,
    save=True,
    cache_path="datasets/my_dataset.pkl"
)

# Load existing dataset
loaded = trainer.load_dataset("datasets/my_dataset.pkl")

# Use in training
trainer.pretrain_columns(
    column_indices=[0, 1, 2, 3],
    dataset=loaded,
    epochs=3
)
```
